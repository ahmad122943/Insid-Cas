طريقة التشغيل كتطبيق:
1) ارفع المجلد كاملًا على استضافة https مجانية (Netlify Drop أو GitHub Pages أو Cloudflare Pages).
2) افتح الرابط من الموبايل أو الكمبيوتر (Chrome/Edge) ثم اختر "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".
3) للتجربة على الكمبيوتر بدون رفع: داخل المجلد شغّل  python -m http.server 8000  ثم افتح http://localhost:8000
ملاحظة: البيانات تُخزَّن على نفس الجهاز والمتصفح، فخذ نسخة احتياطية بشكل دوري.
